# Zerodha-Clone
A full-stack Zerodha Clone built using React, Node.js, Express.js, MongoDB, and Material UI, featuring a trading dashboard, authentication, portfolio management, holdings, positions, and brokerage calculator.

A trading platform developed to replicate the core functionality and user experience of India's leading stock brokerage application.

## Features
- User Authentication (Login/Signup)
- Interactive Trading Dashboard
- Portfolio Holdings Management
- Positions Tracking
- Brokerage Calculator
- Responsive User Interface
- RESTful API Integration
- MongoDB Database Connectivity

## Tech Stack

### Frontend
- React.js
- Material UI
- Bootstrap
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
