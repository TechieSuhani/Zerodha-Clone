# Zerodha Clone

A full-stack Zerodha Clone built using React, Node.js, Express.js, MongoDB, and Material UI, featuring a modern trading dashboard, portfolio management, holdings tracking, positions monitoring, and brokerage calculator.

A trading platform developed to replicate the core functionality and user experience of India's leading stock brokerage application.

---

# Features

* User Authentication (Login/Signup)
* Interactive Trading Dashboard
* Portfolio Holdings Management
* Positions Tracking
* Brokerage Calculator
* Responsive User Interface
* RESTful API Integration
* MongoDB Database Connectivity
* Secure User Sessions
* Real-time Portfolio Data Management
